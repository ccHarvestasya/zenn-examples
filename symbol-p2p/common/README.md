# シリーズ共通のクライアント証明書

`generate_certificates.sh` を初回に一度だけ実行し、各回で同じ証明書と秘密鍵を使います。

```bash
bash generate_certificates.sh
```

実行場所にかかわらず、このディレクトリの `cert/` に保存します。CA 証明書は3650日、Node 証明書は365日有効です。既存のディレクトリがあれば停止し、鍵を上書きしません。

短期間に同じ IP から異なる識別鍵で接続すると、ノード側で接続を拒否されることがあります。各回のコードは、この共通の証明書を既定で読み込みます。秘密鍵を Git に追加せず、シリーズの学習中は同じものを使い、不要になったら削除してください。

出力先を引数で指定することもできます。これはローカル実験・開発者用テストで、一時的な証明書を生成するときに使用します。

```bash
bash generate_certificates.sh /path/to/new-certificate-directory
```
